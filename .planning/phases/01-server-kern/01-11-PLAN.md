| Boundary | Description |

| Fremde resourceUrl zu url-Feld | URLs aus beliebigen Providern erscheinen in der Antwort |

| T-01-76 | Elevation of Privilege | Path Traversal ueber eine manipulierte file:-ID beziehungsweise deren Pfad | mitigate | safe_path() bleibt vor jedem DAV-Zugriff aktiv, ids.parse validiert das Format, Nextcloud erzwingt zusaetzlich die ACL |
| T-01-77 | Tampering | Falsche Aufloesung (Karte statt Notiz) durch Praefix-Verwechslung | mitigate | Zentraler ids-Codec mit Roundtrip-Tests, unbekannte Praefixe werden abgelehnt statt geraten |
