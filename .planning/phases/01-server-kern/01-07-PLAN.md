## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Tool-Parameter zu CalDAV-XML und ICS | Modellgenerierte Texte und Zeiten werden Teil von XML-Bodys und ICS-Dateien |
| CalDAV-Antwort zu Parser | Fremde XML- und ICS-Inhalte werden geparst |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-45 | Tampering | Injection in CalDAV-XML ueber Parameter | mitigate | calendar-query per lxml gebaut, Attribute nur aus konvertierten Datumswerten; kein f-String-XML |
| T-01-46 | Tampering | Injection in ICS ueber summary, location, description | mitigate | ICS ausschliesslich per icalendar erzeugt (Escaping und Folding korrekt), niemals per String-Konkatenation |
| T-01-47 | Denial of Service | XXE und Billion Laughs in der REPORT-Antwort | mitigate | xml.hardened_parser fuer alle Antworten |
| T-01-48 | Tampering | Ueberschreiben eines bestehenden Kalenderobjekts | mitigate | PUT nur mit "If-None-Match: *", 412 wird als Konflikt gemeldet; kein DELETE, kein Update-Tool |
| T-01-49 | Information Disclosure | Credentials in Fehlermeldungen und Logs | mitigate | Geerbte Kontrollen aus Plan 02 (maskiertes repr, from None, httpx-Logger stumm) |
| T-01-50 | Denial of Service | Sehr grosse Zeitraeume liefern zu viele Instanzen | mitigate | limit-Parameter, hartes Timeout pro Kalender, degraded-Markierung statt Haengen |
| T-01-51 | Elevation of Privilege | Path Traversal ueber calendar-Parameter | mitigate | calendarUri wird gegen die Discovery-Liste validiert, nie ungeprueft in den Pfad gehaengt; quote() beim Pfadbau |
| T-01-52 | Spoofing | SSRF | accept | Kein URL-Parameter, Basis-URL aus Env |
