<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| MCP-Client zu Server (stdio) | Der startende Prozess ist die Sicherheitsgrenze, es gibt keine Header und keine Authorization |
| Tool-Parameter zu Nextcloud-Request | Modellgenerierte Strings werden zu Pfaden und XML-Inhalten |
| Server zu Nextcloud | Credentials verlassen den Prozess, Nextcloud authentifiziert und erzwingt ACLs |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-07 | Information Disclosure | Credentials in Logs und Tracebacks | mitigate | Credentials.__repr__ maskiert, "raise ... from None" im graceful-Wrapper, httpx- und httpcore-Logger auf WARNING, kein print im Paket |
| T-01-08 | Spoofing | SSRF ueber die Nextcloud-Basis-URL | mitigate | Basis-URL ausschliesslich aus NC_MCP_URL, kein Tool-Parameter nimmt eine URL, follow_redirects=False, Redirect wird als Konfigurationsfehler gemeldet |
| T-01-09 | Elevation of Privilege | Path Traversal in files_read | mitigate | safe_path() lehnt "..", Backslashes und absolute Fremdpfade ab, quote(path, safe="/") vor dem Requestbau, Test belegt: kein HTTP-Call bei ungueltigem Pfad |
| T-01-10 | Tampering | Create-only-Schreibschutz | transfer | Dieser Plan enthaelt keinen Schreibpfad. dav.py implementiert bewusst nur PROPFIND und GET; die 412-Kontrolle folgt in Plan 03 |
| T-01-11 | Tampering | Injection in WebDAV-XML ueber Tool-Parameter | mitigate | PROPFIND-Body wird per lxml gebaut, nie per f-String; gehaerteter Parser (resolve_entities=False, no_network=True, huge_tree=False) fuer alle Antworten |
| T-01-12 | Elevation of Privilege | Confused Deputy ueber einen Nutzer-Parameter | mitigate | Identitaet nur aus deps.resolve_credentials(ctx); Acceptance-Kriterium prueft alle Input-Schemas auf user/username/uid |
| T-01-13 | Denial of Service | Unbegrenzte Datei-Antwort sprengt den Client-Kontext | mitigate | Groessen-Cap 512 KiB Default, maximal 2 MiB, Truncation-Marker plus next_offset, Binaerdateien abgelehnt |
| T-01-14 | Denial of Service | Brute-Force-Amplifikation gegen die Nextcloud-Instanz | mitigate | Kein Auth-Retry bei 401, 401 und 429 sind Endzustaende mit Handlungshinweis |
</threat_model>
